# Table Kit

Free browser tools for 5th edition tabletop games. Everything runs in the browser and stays there; there is no server or sign-up.

- **Hero Ledger**: character builder for the 2014 and 2024 rules, plus an Excel version.
- **Map Builder**: square and hex maps, generators, fog of war and a player view.
- **Story Manager**: linked campaign notes, quest board, timeline and relationship web.

The site is in `docs/`. Run `python build_site.py` after changing Hero Ledger's source.
